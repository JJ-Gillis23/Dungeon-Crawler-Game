Dungeon Crawler (JavaFX)
Overview

This project is a multi-level dungeon crawler game developed using JavaFX. Players select a character class at the start of the game and progress through increasingly difficult levels by defeating enemies. As the game advances, players can upgrade skills tailored to their chosen class, creating a dynamic and strategic gameplay experience.

Features
Class Selection System
Players can choose from different character classes, each with unique abilities and playstyles.
Progressive Difficulty
Each level introduces stronger enemies and more complex challenges.
Skill Upgrade System
Players earn upgrades as they progress, allowing customization based on their class.
Multi-Level Dungeon Design
The game consists of multiple levels, each with distinct layouts and enemy configurations.
JavaFX User Interface
Built with JavaFX for interactive graphics and smooth gameplay.
Technologies Used
Java
JavaFX
Gameplay
Start by selecting a class.
Navigate through dungeon levels.
Defeat enemies to progress.
Upgrade skills between or during levels.
Survive as long as possible as difficulty increases.
